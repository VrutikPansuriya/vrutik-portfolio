# Vrutik Pansuriya — Portfolio

## Run locally

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Start `index.html` with the Live Server extension, or publish the folder to GitHub Pages.
4. Keep the `assets` and `projects` folders beside `index.html`.

## YouTube embed note

The Souls-like video is embedded directly in its case-study page. YouTube embeds may fail when opening pages from a local `file://` path. Use VS Code Live Server or a hosted HTTPS site such as GitHub Pages so the player receives a normal web referrer. The direct YouTube link remains available below the player.
